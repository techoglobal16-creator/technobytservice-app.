ТЕХНОБЫТСЕРВИС — ЗАДАЧИ v3

Файлы PWA размещаются в корне публичного репозитория GitHub Pages.
index.html, app.js, sw.js, manifest.webmanifest, icon.svg.
Supabase уже настроен. Не публикуйте secret/service_role ключи.

НОВОЕ: приватные вложения до 15 МБ — PDF, DOCX, XLSX, TXT, JPG, PNG, WEBP.
Таблица public.task_attachments и приватный bucket task-attachments созданы в Supabase.
Доступ: администратор и назначенный исполнитель. Общая лента видна активным сотрудникам.
Для просмотра нужен вход; временные ссылки на файлы действуют 5 минут.

Проверка перед эксплуатацией: вход двух сотрудников, создание и назначение задачи, комментарии, фото, файл, закрытие, журнал действий, попытка доступа к чужим вложениям.
Финансовые документы и личные данные клиентов не помещайте в общие комментарии.
Push-уведомления ещё не реализованы.
