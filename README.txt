Публикация: распакуйте архив и загрузите ФАЙЛЫ в корень репозитория GitHub Pages. Замените одноимённые файлы старой версии. Удалите старые дубликаты app (1).js. Убедитесь, что index.html и app.js лежат в корне. GitHub Pages: main / (root).

Встроены только публичные параметры Supabase. Не добавляйте service_role/secret ключи в приложение.
