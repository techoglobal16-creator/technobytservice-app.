ТЕХНОБЫТСЕРВИС v4

1. Публикация: распакуйте архив и замените файлы в корне репозитория GitHub Pages.
2. Android: откройте ссылку в Chrome, меню -> Установить приложение.
3. Windows: откройте ссылку в Chrome/Edge -> Установить приложение.
4. Вход: рабочая почта и пароль Supabase. Администратор активирует пользователя и задаёт роль.
5. Вкладки: Мне назначены / Поставленные мной / Все задачи (админ).
6. Вложение: открыть существующую задачу -> Прикрепить файл.
7. Задачи и закрытые сведения видны только участникам и администраторам.
8. Push-уведомления в v4 пока НЕ реализованы. Не распространяйте как готовую систему с push.
9. Перед реальной эксплуатацией проверьте права двух тестовых сотрудников и загрузку файлов.
10. Пароли и секретные ключи не передавайте сотрудникам в общем чате.
