ТЕХНОБЫТСЕРВИС — ГОТОВЫЙ К ПУБЛИКАЦИИ PWA ПРОЕКТ

Supabase уже подключён к приложению публичным publishable ключом. НЕ используйте service_role или secret key.

1. Создайте отдельный публичный репозиторий GitHub technobytservice-app.
2. Загрузите ВСЕ файлы этой папки в корень репозитория.
3. Settings -> Pages -> Deploy from branch -> main -> /(root).
4. Откройте HTTPS-ссылку GitHub Pages на Android в Chrome и выберите Установить приложение.
5. Войдите под созданным администратором bulat209 (его email и пароль известны только владельцу).
6. Добавляйте сотрудников через регистрацию. Администратор активирует их в приложении.

ВАЖНО: это тестовая версия. Не вводите реальные данные клиентов до проверки RLS на тестовых аккаунтах. Фотографии доступны только назначенным сотрудникам и администратору. Уведомления push ещё не реализованы. В приложении CDN для supabase-js, поэтому для первоначальной загрузки требуется интернет.
