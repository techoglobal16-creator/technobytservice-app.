Подключение общей базы

Для входа сотрудников и синхронизации укажите URL и публичный anon/publishable key проекта Supabase. Не вставляйте service_role или секретные ключи.

Сначала выполните файл schema.sql в SQL Editor Supabase. Инструкции — в README.md.

Вход сотрудников

Новые пользователи не получают доступ к задачам, пока администратор не назначит им роль и филиал. Не пишите телефоны и адреса клиентов в общих комментариях и заметках.

Управление доступом

Роль admin видит все закрытые сведения. Сотрудник видит клиентские данные только по назначенным ему задачам.
